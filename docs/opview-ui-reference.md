- Chrome 桌面視窗設定1440×1000、縮放100%。工具實際輸出包含1425×990、1440×1000，以及最後下鑽畫面1425×731；完整尺寸逐圖列出。最後下鑽保留可讀局部高度，沒有宣稱所有圖片都精確1440×1000。
- 工具原始JPEG畫面以原尺寸轉存PNG，沒有裁切、加註、重繪或以示意圖替代。說明均置於文件。
- 主流程：首頁搜尋鼎泰豐 → 日期選過去3個月 → 重新查詢 → 各區段；期間欄顯示2026-06～2026-09，下載檔名提供2026-06-01～2026-09-06。逐日資料完整度未獨立核對。
- 主條件20項來源，來源限縮測試只選PTT主文／回文。多主題另加入春水堂；分享頁為米其林與必比登、2025-07～2025-09。
- Result網址不保存完整查詢狀態；分頁後URL可能保留page=2或上一區段片段，**以圖中條件與下列操作說明為準**，不能只靠URL還原。
- 時間是截圖保存時間；重新截取已取代較早的未完成畫面。草稿、限制與未驗證操作另標示，不能當成完成結果。
- 未申請帳號或建立公開分享；既有登入與方案狀態未確認。圖片含原站公開文章作者，但不含本機使用者帳號、通知或信件；本系統設計仍維持匿名化。
